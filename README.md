# ماجد فتحي | Majed Fathy Hub

الموقع الرسمي: <https://majdfatihy.github.io/> — فهرس الأدوات والمشاريع المفتوحة المصدر.

## كيف أضيف مشروعاً جديداً؟
1. افتح `data/projects.json` وانسخ أي كتلة مشروع وعدّل بياناتها (`title`, `icon`, `category`, `url`, `description`, `tags`, `cta`).
   الأنواع المتاحة: `tools` و`guides` و`ai` (ويمكن إضافة نوع جديد في `categories`).
2. شغّل `python build.py` (أو ارفع التعديل وسيعمل `.github/workflows/build.yml` تلقائياً).
3. ارفع الملفات المتغيّرة إلى المستودع. يتحدّث `index.html` و`sitemap.xml` و`llms.txt` معاً.

## الملفات
| الملف | وظيفته |
|---|---|
| `data/site.json` | اسم الموقع، القوائم، روابط التواصل، عناوين ووصف الصفحات (SEO) |
| `data/projects.json` | قائمة المشاريع |
| `content/*.html` | نص كل صفحة (≥ 400 كلمة لكل صفحة؛ يتحقق `build.py` من ذلك) |
| `assets/css/site.css` | التصميم |
| `assets/js/site.js` | القائمة والبحث والخلفية الشبكية المتحركة |
| `assets/js/ads.js` | **ملف الإعلانات الخارجي (معطّل)** — الأماكن جاهزة في كل الصفحات |
| `robots.txt` · `sitemap.xml` · `llms.txt` | تُولَّد تلقائياً |

## تفعيل الإعلانات لاحقاً
في `assets/js/ads.js` غيّر `var ENABLED = false;` إلى `true`. الأماكن الجاهزة: `topx` تحت الهيدر، `mid` في الرئيسية، `seo` و`end` قبل الفوتر.

## ملاحظة عن الخلفية
تتحرك الخلفية دائماً (بسرعة أبطأ إذا كان النظام يطلب تقليل الحركة)، ويوقفها الزائر بالزر في أسفل الصفحة.
